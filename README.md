# 诗成双曜 · 李白与杜甫的诗语对读

一个纯静态的**数字人文**可视化站点：以李白与杜甫的全部分句语料为底本，从字频、意象密度、句长节奏、篇制结构与诗语重合五个维度，对读两座唐诗高峰。

宣纸底、水墨插图、竖排章节、朱印收尾，无需构建工具，可直接部署到 GitHub Pages。

---

## 站点内容

| 卷 | 标题 | 内容 |
| --- | --- | --- |
| 卷一 | 序 | 两幅水墨立轴、卷首语与项目缘起 |
| 卷二 | 量 | 诗数、句数、字数、独用字、平均句长与篇长 |
| 卷三 | 字 | 两张字云，字号＝出现次数，悬停显示次数 |
| 卷四 | 象 | 32 个意象字按「每千字出现次数」折算对比 |
| 卷五 | 律 | 五言／七言／其他占比（竹简条）＋ 每首句数分布 |
| 卷六 | 逢 | 共享两字词排行 ＋ 可交互的「诗语相逢图」 |
| 过场 | 山河 | 李白「山随平野尽，江入大荒流」对 杜甫「星垂平野阔，月涌大江流」 |
| 卷七 | 对读 | 三字以上重合的真实句对卡片，红字标出共享字 |
| 卷八 | 检 | 全语料检索：输入字词，返回两家的整首诗并高亮命中 |

交互均为原生实现：滚动入场、数字滚动、条形生长、章节导航、卡片换批、异步载入诗库检索。

## 目录结构

```
.
├── index.html              # 页面（全部章节与文案）
├── assets/
│   ├── css/style.css       # 全部样式：宣纸肌理、竖排、配色
│   ├── js/app.js           # 全部交互与图表渲染（无依赖）
│   └── img/                # 水墨插画（AI 生成，仅作氛围）
├── data/
│   ├── 李白.csv            # 原始语料：诗题, 诗句, 页/诗编号, 句序号
│   ├── 杜甫.csv
│   ├── 李白-杜甫.csv       # 句对候选表：11 列，含两家的诗题、诗句与编号
│   ├── site-data.js        # 站点指标（由 scripts/build_data.py 生成）
│   └── poems.js            # 检索用诗库（诗题 + 全文）
└── scripts/build_data.py   # 从 CSV 重新生成上述两份数据
```

## 三种打开方式

| 方式 | 用途 |
| --- | --- |
| `诗成双曜.html`（单文件） | 样式、脚本、数据、插图全部内嵌，双击即开，无需其他文件；适合发给别人看 |
| 本目录 + `python3 -m http.server` | 完整工程版，开发与调试用 |
| 上传到 GitHub Pages | 公开发布 |

单文件由 `python3 scripts/build_single.py` 从工程版自动打包生成，改完工程版重跑即可同步。

## 本地运行

页面通过 `<script>` 载入数据，因此 `index.html` 直接用 `file://` 打开也能看；但「卷八 检」的诗库为异步加载，建议用本地 HTTP 服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 部署到 GitHub Pages

1. 新建仓库，把本目录全部文件推到 `main` 分支根目录。
2. 仓库 **Settings → Pages**：Source 选 *Deploy from a branch*，Branch 选 `main` / 根目录。
3. 稍等片刻，访问 `https://<你的用户名>.github.io/<仓库名>/`。

无需 Actions、无需构建产物，照片与字体都在仓库内（不依赖任何外部 CDN）。

## 数据说明

- 三份 CSV 均以 UTF-8（含 BOM）编码，无表头。
- `李白.csv` / `杜甫.csv`：`诗题, 诗句, 编号A, 句序号`，按诗句切分，保留原文标点。
- `李白-杜甫.csv`：每行一组候选句对，字段依次为 `李白, 李诗题, 李诗句, 杜甫, 杜诗题, 杜诗句, 编号A, 编号B, 诗句序号B, 编号C, 诗句序号C`。
- 句对表是**按字符重合度机械筛出的候选**，不是「化用／抄袭」的判定。全表 23,448 行，其中三字以上重合 2,154 行，整句完全相同仅 2 行。
- 网页上的所有指标（字频、每千字意象频次、五言七言比、篇制分布、两字词支持数）都由 `scripts/build_data.py` 从原始 CSV 现算，没有引入任何外部数据。

重新生成数据：

```bash
python3 scripts/build_data.py   # 读取 data/*.csv，输出 data/site-data.js 与 data/poems.js
```
