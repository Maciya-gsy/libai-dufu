卷一

序

两份分句表、一份句对表——这里没有诗话，只有被摊平的字。
我们把李白的 1,073 首与杜甫的 1,409 首诗， 逐句拆成可数的单位，看两座相邻的山，山势究竟哪里不同。

「李杜」并称千年，读者惯于把他们放在同一副天平上。可是文学史上的高下之争，多半靠印象与偏爱裁决；而印象之外，诗是可以用另一种方式被看见的——数一数他写了多少句五言，数一数「月」出现过几次，数一数两人在同一片诗语土壤里各自种下了什么。

本卷所据，是三份表格：李白与杜甫各自的逐句语料，以及一份由字符重合度筛出的「李杜句对」候选表，共 23,448 组。它们不是文学结论，只是路标：告诉我们在哪里值得停下来多看一眼。

因此这里不做判定，只做陈列。看数字如何把「飘逸」与「沉郁」这两个说惯了的词，还原成一串可以核对的差异。

卷二

量

先看体量。杜甫传世之作比李白多出三成，字数多出两万七千；但两人的平均句长， 却意外地几乎相等——一个以五言为主的世界，谁也没能走得更远。

多出来的三成 杜甫多出的 336 首诗，并未带来更长的句子。平均句长 5.34 与 5.41，只差 0.07 字——五言的引力场，两人都没能真正离开。
更宽的字盘 杜甫动用了 4,290 个不同的字，比李白多出 802 个。字盘越宽，通常意味著题材越杂：吏治、农事、疾病、器物，都往诗里挤。
一句话的边界 两人平均每首 13.5 与 13.7 句，听起来几乎一样；但把篇幅结构摊开（见卷五），差别立刻显形。
卷三

字

字频是一个人下意识的呼吸。两张字云里，「不」与「人」都排在最前—— 唐人写诗，最常写的其实是否定与人。往下再读，分歧才开始。

李白的高处是「天」 天 634 次、山 563、云 561——他惯于把视线抬起来，让句子往高处走。
杜甫的高处是「日」与「江」 日 593、江 564、风 570——他的镜头更贴著地面与水面，日子与江水都是要一天天熬过去的东西。
共同的底色 白、不、何、一、相、来、君——这些字在两张字云里都靠前。唐诗的公共词汇，先于诗人的个性存在。

象

意象的偏爱，比字频更接近诗人的性情。下图按每千字出现次数折算—— 只有折算过，才能公平地比：杜甫写得多，却不一定写得密。

李白 杜甫

月 6.2 : 2.2　李白笔下的月，密度是杜甫的近三倍。月亮在他那里是可邀可问的对象；在杜甫那里，更多是夜里的一个背景。

江 3.0 : 5.4　反过来，「江」属于杜甫。三峡、夔州、草堂，他的中年以后几乎是被水推著走的。

剑 18 : 0　全站最锋利的一组数字：李白写「剑」18 次（每千字 0.2），杜甫 0 次。任侠与书生，不需要论证。

老 375 : 74，病 162 : 8　杜甫写「老」的密度是李白的近四倍，写「病」是十五倍。身体，是他诗里无法绕开的坐标。

卷五

律

句子的长短只是表皮，一首诗由几句组成，才见章法的性格。 把每首诗的句数点出来，两人的形状立刻不同：杜甫把超过一半的诗，都压进了八句。

八句一诗是律诗的体格。杜甫有 791 首诗恰好八句，占其全部诗作的 56%； 李白只有 277 首，占 26%。相反，四句的绝句李白有 192 首、杜甫 135 首。 换句话说：李白更常一阵风写完就走，杜甫更常把自己按进格律的框子里，反复打磨中间两联。 五言与七言的比例，两人却都停在七成七与两成之间——同样的字数偏好，截然不同的篇幅习惯。

逢

两人相差十一岁，一生只见过寥寥数面，却在最日常的两字词里频繁相逢。 下图统计的是：在句对候选表中，「同一个两字词」被多少组句对同时支持。

中央是两人共用的词，左侧引李白原句，右侧引杜甫原句。 点一颗节点，下方展开它的出处——这是把「互文」还原成可以逐条核对的句子。

李白 · 共用的两字词 · 杜甫
不是抄袭，是土壤 这 23,448 组句对是按字符重合度机械筛出的候选，并非判定「化用」。其中 2,154 组有三字以上重合，仅 2 组整句完全相同（「百里见秋毫。」）。
万里、白发、萧萧 排在最前的词，多与远行、衰老、风声有关。唐人共用的一套抒情零件，被两人各自装配成了不同的机器。
「路难」与「别离」 李白写「行路难」，杜甫写「别离」——同样是困境，一个向外抗争，一个向内承受。
